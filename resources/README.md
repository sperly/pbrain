# PocketBrain logo

PocketBrain is the wordmark. A sprouting pea is the mascot and can stand on its own.

| File | Use |
|---|---|
| pocketbrain-web.svg | Full-color logo with the wordmark for a light web background. The letters are vector paths. |
| pocketbrain-icon.svg | Standalone pea for an app icon or favicon. |
| pocketbrain-emboss.svg | Single-color compound outline for importing as a CAD profile. The face and leaf details are cutouts. |
| pocketbrain-emboss-18mm.stl | Raised mark, 18 mm wide, approximately 19.9 mm tall, and 0.6 mm thick. |
| PocketBrain_Logo_Preview.png | Preview of the web logo, icon, and simulated case relief. |

For the enclosure, import the SVG and scale the outline to the desired width
before extruding. Alternatively, position the STL on the case and union it
with the shell. The STL mesh was checked for watertightness and dimensions.
Print a small test on your chosen case material before setting the final size
and relief depth.

The web mark uses pea green (#A4D760), leaf green (#55A254), and dark green
(#203924). The green part of the wordmark uses #35713B.
